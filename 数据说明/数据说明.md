# 一.`逐句原始数据`表字段说明

## 工作表信息
- **工作表名称**：逐句原始数据
- **数据内容**：每条记录（行）对应一个句子的指标分析结果

## 字段详细说明

### 1. 标号 (A列)
- **含义**：所有句子的唯一标识符
- **格式**：从1开始的连续编号（1-N）


### 2. 主题 (B列)
- **含义**：该句子所属的主题领域
- **示例**：碳达峰、工业领域、城乡建设领域等


### 3. File (C列)
- **含义**：该句子所属的源文件名
- **示例**：`2030年前碳达峰行动方案.docx`、`上海市碳达峰实施方案.docx`


### 4. Query (D列)
- **含义**：作为参照基准的具体句子
- **特点**：
  - 同一主题下，所有文件的query内容完全一致
  - 对应中央文件（如《2030年前碳达峰行动方案》）的逐句分句结果
- **作用**：不同地方以同一篇中央文件作为参照，建立统一的比较基准，确保不同地方文件的可比性

**示例说明**：
![本地路径](pic\1.png)
- 碳达峰主题下，《2030年前碳达峰行动方案》和《上海市碳达峰实施方案》的query完全相同
- 中央文件（标号1-341）与上海文件（标号342-682）的query一一对应，均为中央文件的分句结果

### 5. Match (E列)
- **含义**：基于SBERT相似度计算，在File文件中与query最相似的句子
- **技术**：使用Sentence-BERT模型计算语义相似度


### 6. Query_structure (F列)
- **含义**：query句子在中央文件中的段落位置信息
- **作用**：标识句子在原文中的结构层级和归属

### 7. Match_structure (G列)
- **含义**：match句子在File文件中的段落位置信息
- **作用**：标识匹配句子在地方文件中的结构位置

### 8. Direct_sim (H列)
- **含义**：query与match之间的语义相似度得分
- **范围**：0-1之间的数值，越接近1表示相似度越高
- **作用**：量化中央与地方文件内容的相似程度

### 9. Direct_degree (I列)
- **含义**：match与query的相对语调差异
- **计算方式**：match的语义程度总分 - query的语义程度总分
- **解读**：
  - 正值：match比query语气更强
  - 负值：match比query语气较弱
  - 零值：语气程度相当
  - 词典：具体的语义值参考语义词典中的打分（sheet3 语义词典）

## 数据关系说明

本质是：**以中央文件为基准，横向比较各地方文件的对应内容**。

- **纵向关系**：同一文件内句子的顺序结构
- **横向关系**：不同文件间相同query的对比分析
- **分析维度**：通过相似度(direct_sim)和语调差异(direct_degree)量化地方文件对中央文件的相似程度和相对语调

# 二、`文件聚合数据`表字段说明
## 工作表信息
- **工作表名称**：文件聚合数据
- **数据内容**：每条记录（行）对应一个文件的指标分析结果

## 字段详细说明

### 1. fields (A列)
- **含义**：该文件所属的主题
- **示例**：碳达峰、工业领域、城乡建设领域等

### 2. id (B列)
- **含义**：该文件的唯一标识符
- **格式**：1-168

### 3. 地区 (C列)
- **含义**：文件所在的地区
- **示例**：中央（2030年前碳达峰行动方案）；上海（上海市碳达峰实施方案）


### 4. file (D列)
- **含义**：具体的文件名

### 5. 时间(E列)
- **含义**：每篇文件的发布时间
- **格式**：YYYY/MM/DD

### 6. avg_direct_sim (F列)
- **含义**：`逐句原始数据`中该file文件所有句子的direct_sim平均值
- **示例**：`2030年前碳达峰行动方案`的avg_direct_sim为1，是通过对`逐句原始数据`中该文件对应的第1-341号句子的direct_sim值求平均得到的(因为中央和中央自己参照的相似度肯定是1)

### 7. avg_direct_degree (G列)
- **含义**：`逐句原始数据`中该file文件所有句子的direct_degree平均值
- **示例**：`2030年前碳达峰行动方案`的avg_direct_degree为0，是通过对`逐句原始数据`中该文件对应的第1-341号句子的direct_degree值求平均得到的（中央和中央自己的语调肯定是一致的）

### 8. 0.25 (H列)
- **含义**：`逐句原始数据`中该file文件所有相似度**高于0.25**的句子的direct_degree平均值
- **解释**：和avg_direct_degree是同一类指标，只是这里做了一定程度上相似度的控制，这里相似度阈值越高，理论上语义指标值会越稳健；后面的0.5/0.75也是同样的目的

### 8. 0.5 (I列)
- **含义**：`逐句原始数据`中该file文件所有相似度**高于0.5**的句子的direct_degree平均值

### 8. 0.75 (J列)
- **含义**：`逐句原始数据`中该file文件所有相似度**高于0.75**的句子的direct_degree平均值
