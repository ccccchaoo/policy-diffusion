# 项目文件说明

## 1. 原始数据
- **位置**：`数据说明` 文件夹中
- **文件**：`数据表.xlsx`
- **包含工作簿**：
    1. **逐句匹配结果**（最原始数据）
    2. **各地方文件结果**（按文章平均）
    3. **语义词典**
- **详细说明**：请参阅 `数据说明` 目录下的 `数据说明.md` 文件

## 2. 汇报PPT
- **文件**：内容汇报的PPT
- **内容特点**：
    - PPT 后半部分包含了目前涉及到的所有图表
    - **未隐藏的图表**为当前正在使用的版本

## 3. 草稿文档
- **文件**：当前工作的思路和结论草稿
- **内容特点**：
    - 对研究思路和结论的解释比PPT更为详细
    - 反映了当前的工作进展和思考过程
